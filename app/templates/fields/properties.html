Usage Types

  • Games & Practices - Field can be used for both (default)
  • Games Only - No practices scheduled here
  • Practice Only - No games scheduled here (e.g., Shepard, Southern Boundaries 1)

Practice Capacity

  • Practice Capacity - How many teams can practice at the same time
  • Late Slot Capacity - Different capacity for late time slots (e.g., 7:30 PM):
    • Same - Use the same capacity as the early slot
    • No Practices - Don't use this field for late practices
    • 1-4 teams - Specific capacity for late slots

Example: Parkwood can hold 2 teams at 5:30 PM but only 1 team at 7:30 PM. Southern Boundaries 2 has no lights, so set Late Slot to "No Practices".
