What does "releasing" the schedule do?

When you're building a schedule, you make lots of changes - moving games around, adjusting times, swapping fields. These are all tracked by the system.

Once you officially release the schedule to coaches and families, you want to start fresh:

  • Public schedule pages won't show "Originally scheduled for..." for any pre-release changes
  • Pending notifications for pre-release changes will be cleared (no one needs to be notified about changes made before they even saw the schedule)
  • Future changes (after release) will still show up and trigger notifications as expected

This is a one-time action per season. You can safely release multiple times if you make more pre-release changes later.
